# Web nueva de DeTurista

Rediseño completo de deturista.com (UX, UI, iconografía, componentes). La web nueva se arma de cero sobre la API del admin de DeTurista (prevista para febrero 2027).

- `relevamiento/`: fase 0, cómo funciona la web actual y qué datos tiene que dar la API por pantalla.
- `DISENO.md`: todo lo que hay que diseñar (fundamentos, íconos, componentes, pantallas, imágenes, textos), con casos límite reales.
